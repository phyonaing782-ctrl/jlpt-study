# JLPT Japanese Study App

Offline-first mobile study app prototype for Burmese learners.

## Included
- N5: 25 ordered lessons
- N4: lessons 26–50 (25 lessons)
- N3: 20 thematic units
- Japanese + Burmese examples
- Mini Quiz
- Local progress saved on the device
- Past Exam section prepared for user-owned/licensed materials

## Android
This prototype is a PWA. On Android Chrome, open the folder through a hosted/local web server and use **Add to Home screen** for an app-like experience.

For a native APK, wrap this web app with Capacitor/Android Studio. An Android SDK is not installed in this build environment, so an APK cannot be compiled here.
